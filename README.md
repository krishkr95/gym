# Alpha Fitness Gym - Premium Gym Website

A high-converting, premium, modern, and fully responsive gym website for **Alpha Fitness Gym, Sahibganj**, built with pure HTML5, CSS3, and Vanilla JavaScript. Tagline: **Train Hard. Be Alpha.**

## Features

- **Dark Premium Theme** with glassmorphism cards and smooth animations
- **Fully Responsive** - works on desktop, laptop, tablet, and mobile
- **WhatsApp Integration** - dynamic messages for membership plans, personal training, and free trial
- **Interactive Tools** - BMI Calculator, Calorie Calculator, Countdown Timer
- **Testimonial Carousel** - auto-sliding with navigation controls
- **Gallery Lightbox** - full-screen image viewer with keyboard navigation
- **FAQ Accordion** - smooth expand/collapse functionality
- **Lead Capture Form** - submits via WhatsApp with pre-filled details
- **Scroll Animations** - IntersectionObserver-based reveal animations
- **SEO Optimized** - semantic HTML, meta tags, Open Graph, schema markup

## Setup

1. Open `index.html` in any modern browser
2. No build tools or dependencies required
3. Images load from Unsplash CDN

## Customization

- **WhatsApp Number**: Change `CONFIG.whatsappNumber` in `js/script.js`
- **Colors**: Modify CSS variables in `css/style.css` `:root` section
- **Content**: Edit text directly in `index.html`
- **Images**: Replace Unsplash URLs with local images in the `images/` folder
